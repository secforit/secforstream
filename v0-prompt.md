# v0.dev Prompt for StreamProof Landing Page

Create a modern, eye-catching landing page for StreamProof - a crypto token that verifies livestream authenticity and prevents deepfakes.

## Design Style
- **Aesthetic**: Modern, sleek, tech-forward with purple/indigo gradient accents
- **Vibe**: Trust, security, futuristic, anti-AI verification
- **Colors**:
  - Primary: Indigo/Purple gradient (#6366f1 to #8b5cf6)
  - Secondary: Dark background with subtle gradients
  - Accent: Bright cyan/blue for CTAs (#3b82f6)
- **Typography**: Clean, sans-serif, high contrast for readability
- **Layout**: Single-page scroll with distinct sections

## Sections to Include

### 1. Hero Section (Above the Fold)
**Content:**
- **Main Headline**: "Prove You're Real. Verify Your Stream."
- **Subheadline**: "Fight deepfakes with real-time verification challenges. Streamers stake tokens, viewers participate, everyone proves they're human."
- **Two CTA Buttons**:
  - Primary: "Join Discord" (bright, prominent)
  - Secondary: "View Whitepaper" (outlined)
- **Visual Element**: Animated shield icon or checkmark that pulses, OR abstract illustration showing a streamer being verified with checkmarks/badges

**Design Notes:**
- Large, bold headline typography

## Technical Requirements

### Responsive Design
- Mobile-first approach
- Breakpoints: Mobile (320px+), Tablet (768px+), Desktop (1024px+)
- Stack sections vertically on mobile
- Hamburger menu for mobile navigation

### Interactions
- Smooth scroll to sections
- Hover effects on cards and buttons
- Animated counters in metrics section
- Subtle parallax or scroll-triggered animations
- Hero section should have micro-interactions

### Performance
- Optimize images and icons
- Lazy load sections below the fold
- Fast initial load time
- Use modern CSS (Grid, Flexbox)

### Accessibility
- High contrast text
- Proper heading hierarchy
- Alt text for images
- Keyboard navigation support
- ARIA labels where appropriate

## Brand Guidelines

### Colors
```
Primary Gradient: linear-gradient(135deg, #6366f1 0%, #8b5cf6 100%)
Background Dark: #0f172a
Background Light: #f8fafc
Accent Blue: #3b82f6
Success Green: #10b981
Warning Red: #ef4444
Text Primary: #ffffff (on dark) / #1e293b (on light)
Text Secondary: #94a3b8
```

### Typography
- Headings: Inter, SF Pro Display, or similar modern sans-serif
- Body: Inter, System UI, or similar
- Weights: Regular (400), Medium (500), Semibold (600), Bold (700)

### Spacing
- Consistent padding: 1rem, 2rem, 4rem, 6rem
- Section padding: 4rem vertical on desktop, 2rem on mobile
- Component spacing: 1-2rem between elements
